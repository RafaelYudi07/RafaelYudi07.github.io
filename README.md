# Mizu Connect | Portfólio profissional

Mizu Connect é o portfólio profissional de Rafael Yudi, com foco em desenvolvimento de software, integrações e automações. Apresenta minha trajetória, competências e projetos com Kotlin, Android, Python, APIs REST e Bitrix24.

## Conteúdo

- Apresentação profissional e links de contato.
- Projetos com filtros por área: automações e CRM, Android e web.
- Experiência com implantação e integrações Bitrix24 na WCF.
- Calculadora de IMC, aplicativo de tarefas e projeto web Multiverso Spider-Man.
- Trajetória profissional e competências técnicas.
- Simulação de um fluxo de automação e demonstração de cálculo de IMC no navegador.

As demonstrações são executadas localmente no navegador. O fluxo de CRM é ilustrativo e não se conecta a sistemas reais. A calculadora web demonstra a lógica de cálculo e não corresponde ao aplicativo Android original. As imagens dos projetos são representações visuais, não capturas das aplicações.

## Tecnologias

O site utiliza HTML5, CSS3 e JavaScript, sem frameworks ou dependências de instalação. Inclui layout responsivo, navegação por teclado e suporte à preferência por movimento reduzido.

## Visualização local

Baixe os arquivos e abra `index.html` no navegador. Não é necessário instalar pacotes nem executar uma etapa de compilação.

## Publicação no GitHub Pages

1. Crie um repositório público chamado `RafaelYudi07.github.io` na conta `RafaelYudi07`.
2. Envie `index.html` e `README.md` para a raiz do repositório.
3. Abra **Settings → Pages**.
4. Em **Build and deployment**, escolha **Deploy from a branch**.
5. Selecione a branch `main`, a pasta `/ (root)` e clique em **Save**.
6. Aguarde o GitHub informar a conclusão da publicação.

O endereço previsto após a publicação é [rafaelyudi07.github.io](https://rafaelyudi07.github.io/).

## Atualizações

Edite o arquivo `index.html` para atualizar textos, projetos, estilos e links. Envie a versão atualizada para a branch configurada no Pages para iniciar uma nova publicação.

Sugestões e correções podem ser propostas por issues ou pull requests. Antes de adicionar uma experiência ou resultado profissional, confirme as informações com o autor.
